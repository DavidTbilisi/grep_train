    Cheat Sheet
    
                    
    
                        
    grep: find lines
    
                        
    grep [options] PATTERN FILE
    
                        
    
                            
    -i ignore case
    
                            
    -v invert: lines that do NOT match
    
                            
    -c count matching lines
    
                            
    -n show line numbers
    
                            
    -w whole words only
    
                            
    -o print only the matched text
    
                            
    -E extended regex: 'A|B', +, {3}
    
                            
    -A/-B/-C N N lines of context after / before / around
    
                        
    

                        
    Regular expressions
    
                        
    
                            
    ^ $ start / end of the line: '^ ', 'lost$'
    
                            
    [0-9] [a-c] [^ ] one character from a set (^ inside means "not")
    
                            
    -w whole words only: grep -w in skips Loading
    
                            
    + {3} .* with -E: one or more, exactly three, anything
    
                            
    -o print only the matched part: grep -oE '[0-9]+ms'
    
                        
    

                        
    Log analysis tools
    
                        
    
                            
    cat FILE print a whole file
    
                            
    head -n N first N lines
    
                            
    tail -n N last N lines (newest log entries)
    
                            
    wc -l count lines
    
                            
    sort sort lines (-n numbers, -r reverse, -u unique, -k N by column)
    
                            
    uniq -c collapse repeats and count them (sort first!)
    
                            
    cut -d' ' -f2 column 2, split on spaces
    
                            
    awk '{print $2}' column 2, split on whitespace
    
                            
    awk '$5 == 404' lines where column 5 is 404
    
                        
    

                        
    awk totals
    
                        
    
                            
    {s += $6} END {print s} add up a column, print the total once at the end
    
                            
    END {print s/NR} average: NR is the number of lines
    
                            
    $6 > max {max = $6} keep the biggest value seen
    
                            
    {b[$2] += $6} a total per key (arrays)
    
                            
    END {for (k in b) print k, b[k]} print every key and total (then | sort)
    
                            
    printf "%.1f\n", x one decimal place
    
                        
    

                        
    Pipes
    
                        
    A pipe | feeds one command's output into the next. Real log analysis is
                            just small tools chained together:
    
                        
    grep ERROR app.log | wc -l
    
                        
    awk '{print $2}' access.log | sort | uniq -c | sort -rn | head -n 3
